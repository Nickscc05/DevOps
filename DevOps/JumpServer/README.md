## ---------  JUMPSERVER  ---------

# CONCEITO 

- O **JumpServer** é uma ferramenta open source (código aberto) de PAM (Privileged Access Management) - Ou seja, um "bastion host"/ gateway de acesso privilegiado. 
- Ao inves de dar a cada administrador acesso direto e disperso aos servidores, você centraliza todo o acesso a ativos de infraestrutura através dele, via navegador ou clientes SSH/RDP. 
- É uma ferramenta de código aberto de Gerenciamento de 

PONTO UNICO DE ACESSO A SERVIDORES
